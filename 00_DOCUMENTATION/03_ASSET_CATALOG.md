# Catalogue de tri — vue d'ensemble

Le dossier de départ contenait 151 fichiers : 142 images/GIF et 9 vidéos MP4. Les noms d'origine ont été préservés ; le rangement par dossiers est le premier niveau d'indexation.

Le détail machine-readable se trouve dans `asset_manifest.csv`, afin de pouvoir alimenter plus tard une galerie web, un CMS ou un catalogue de jeu.

## Catégories

| Dossier | Usage | Exemples de motifs |
|---|---|---|
| `01_CANON_BWED` | identité, Bwed de base, cast et variantes | tranche de pain, groupe de Bwed, métiers, costumes |
| `02_WORLD_AND_STORIES` | lieux, aventures, récits | mer, Lune, pyramide, école, banque, portail |
| `03_MEMES_AND_SOCIAL` | memes, web3, historique communautaire | HOLD, UP, Solana, Binance, Pump.fun, slogans |
| `04_ANIMATION_AND_VIDEO` | mouvement et formats courts | MP4, GIF |
| `05_PHYSICAL_AND_MERCH` | présence matérielle | plush, colis, collection, photos |
| `06_BRAND_AND_HUB` | présentation, titres, promo et UI | wordmarks, panneaux, assets de hub |
| `99_REVIEW_TO_CANONIZE` | éléments dont le statut doit être décidé | crossovers ou sources inconnues |

## Lecture importante

Le rangement ne prétend pas établir la chronologie de création. Les identifiants numériques des fichiers semblent venir d'exports ou de plateformes et ne sont pas suffisants pour dater l'histoire. La chronologie doit être reconstruite séparément à partir des posts, contrats, wallets, archives sociales et souvenirs de l'équipe.
